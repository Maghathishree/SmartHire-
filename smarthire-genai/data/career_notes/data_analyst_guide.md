# Comprehensive Career Guide: Becoming a Data Analyst

## Overview
A Data Analyst collects, cleans, analyzes, and visualizes data to help organizations make strategic business decisions. They serve as the critical bridge between technical data engineering systems and non-technical business leaders.

## Core Technical Skills Required
1. **SQL (Structured Query Language)**: 
   - Essential mastery: Window functions (ROW_NUMBER, RANK, LEAD, LAG), Common Table Expressions (CTEs), multi-table joins, subqueries, group by aggregations, and query optimization.
   - Recommended tools: PostgreSQL, MySQL, Google BigQuery, Snowflake.

2. **Spreadsheet Modeling**:
   - Advanced Excel / Google Sheets: VLOOKUP/XLOOKUP, INDEX-MATCH, Pivot Tables, Power Query, conditional formatting, dynamic charts, and financial modeling.

3. **Data Visualization & BI Tools**:
   - Tableau: Calculated fields, parameters, LOD expressions (Level of Detail), interactive dashboard actions.
   - Power BI: DAX formulas, Power Query M language, data modeling (star schema vs snowflake schema), row-level security.

4. **Python for Analytics**:
   - Pandas for data manipulation, cleaning missing values, and reshaping datasets.
   - NumPy for numerical transformations.
   - Matplotlib and Seaborn for statistical data visualization.

5. **Applied Statistics & Business Acumen**:
   - Descriptive statistics (mean, median, variance, interquartile range).
   - Inferential statistics (hypothesis testing, p-values, t-tests, ANOVA, Chi-Square).
   - A/B testing design, sample size calculation, conversion rate optimization, and cohort retention analysis.

## Recommended Career Roadmap
- **Phase 1 (Months 1-2)**: Master advanced SQL and Excel. Solve SQL 50 challenges on LeetCode/HackerRank.
- **Phase 2 (Months 3-4)**: Learn Tableau or Power BI. Build 2-3 public dashboard portfolios hosted on Tableau Public or NovyPro analyzing real Kaggle datasets (e.g. Sales, Healthcare, Churn).
- **Phase 3 (Months 5-6)**: Learn Python (Pandas/Seaborn). Conduct exploratory data analysis (EDA) and automate recurring reports.
- **Phase 4 (Months 7-8)**: Prepare for case study interviews, A/B testing scenarios, and present business insights with storytelling.

## Interview Preparation & Resume Advice
- Quantify every resume bullet point: Instead of "Built dashboard for sales", write "Engineered an automated Power BI executive dashboard tracking $4.2M in annual recurring revenue across 12 sales regions, reducing weekly reporting time by 6 hours."
- Showcase an end-to-end portfolio project featuring data ingestion, SQL cleaning, exploratory data analysis, and an interactive business dashboard.
