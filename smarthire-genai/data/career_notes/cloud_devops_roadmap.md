# Career Guide & Roadmap: Cloud & DevOps Engineering

## Overview
Cloud and DevOps Engineers automate software delivery pipelines, ensure high availability, design resilient cloud architectures, and optimize infrastructure cost and security.

## Core Competencies
1. **Linux Systems & Networking Fundamentals**:
   - Shell scripting (Bash), file permissions, systemd service management, process monitoring (top, htop), network troubleshooting (curl, netstat, ping, dig, iptables, DNS, TCP/IP, SSL/TLS certificates).

2. **Containerization & Orchestration**:
   - Docker: Multi-stage builds, minimal base images (Alpine / distroless), Docker Compose, volumes, networking.
   - Kubernetes (K8s): Pods, Deployments, Services, Ingress, ConfigMaps, Secrets, Helm package charts, Horizontal Pod Autoscaling (HPA).

3. **Infrastructure as Code (IaC)**:
   - Terraform: Declarative configuration, state management, modules, providers (AWS, GCP, Azure).
   - Ansible: Configuration automation, playbook writing.

4. **Continuous Integration & Continuous Deployment (CI/CD)**:
   - GitHub Actions, GitLab CI, Jenkins.
   - Automated linting, test suites, container image security scanning (Trivy), zero-downtime blue/green or canary deployments.

5. **Cloud Providers (AWS / GCP / Azure)**:
   - Compute: EC2, Cloud Run, Lambda, Google Kubernetes Engine (GKE).
   - Storage & Networking: S3, VPCs, Subnets, Route 53, CloudFront / CDN.
   - Observability: Prometheus, Grafana, CloudWatch, Datadog, ELK stack for centralized log aggregation.

## Resume Advice for Cloud / DevOps
- Emphasize automated outcomes rather than manual setup:
  - Weak: "Set up AWS EC2 instances and Docker."
  - Strong: "Configured Terraform templates provisioning automated multi-AZ AWS infrastructure with auto-scaling groups, reducing server operational expenditure by 28% while maintaining 99.95% uptime."
